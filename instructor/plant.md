# Plant block — facilitation

This first teaching draft supports the established physiology core. It is not
an approved assessment scheme or a replacement laboratory manual. No R,
database subscription, specimen handling or transformation procedure is needed.

## Outcome and activity map

| Unit | Main understanding |
| --- | --- |
| P1 | Cellular organisation, growth and tissue function |
| P2 | Resource acquisition, transport and regulation |
| P3 | Photosynthesis, metabolism and carbon distribution |
| P4 | Signalling, development and reproduction |
| P5 | Stress, biotechnology and ethical evaluation |

These map primarily to the plan's plant-process outcome, with P5 addressing
genetically modified plants' benefits/risks/ethics. Experimental reasoning and
scientific communication recur throughout. Normal-tissue identification on
actual material still requires the established practical sessions; a written
description is not evidence of microscope proficiency.

Use the unit tutorial for independent preparation, the 12-slide deck for a
focused concept discussion and the exercise for practice. A whole
unit can need several teaching meetings; the deck is not a claim that the
entire topic fits one short lecture. Quiz answers are student-visible for
self-study, and the exercise pages show an answer under each question.

## Exercise answers

Each unit's exercise page gives a worked answer under every question.
The exercises are closed questions (definitions, calculations, ordering,
matching, classification and tables) with one expected answer each.

## Instructor review before delivery

Confirm actual required reading sections, specimen resources, laboratory
protocols and formal outcomes. Match exercises to available time and protected
practical hours. Check accessibility of diagrams and symbol notation. The
draft provides original schematics and invented classroom data; it contains
no copied textbook figures or claimed new laboratory validation. Obtain actual
practical datasets before deciding whether an optional R workflow would help.
